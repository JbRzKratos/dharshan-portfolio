## Preview
Double-click Preview.cmd on Windows to start a local preview. Keep its window open while viewing, and close it when finished. Python must be installed (it is available on this computer).

Open index.html for a basic preview. For all interactions, serve this folder with a local static server, for example: `python -m http.server 8080`, then visit http://localhost:8080.
